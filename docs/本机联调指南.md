# 测试号本机联调

本配置用于用户确认的小程序测试号 `wx8e2380dec308d5de`，供微信开发者工具模拟器联调。支付、退款和账户余额均为模拟数据，不会向微信支付发起扣款。原云环境及其用户资产未改动。本机数据库持久保存，停止/重启不会清空联调数据。

## 启动与访问

在终端执行：

```sh
cd /Users/yangl/IdeaProjects/wmall/server
npm run local:start
npm run local:status
```

首次启动会初始化独立的本机MySQL（`127.0.0.1:33317`）、创建 `pandou_local_dev` 数据库、导入初始菜品并执行001–009迁移。使用独立应用账号；凭据自动生成，只保存在忽略目录 `.runtime/local-dev/config.json`，不要提交或分享该文件。该脚本不读取现有云环境凭据。

后端地址为 `http://127.0.0.1:18080`，健康检查为 `/api/health`。原8080端口被其他应用占用，本项目不停止该应用。启动后服务在后台运行，可以关闭启动终端。

微信开发者工具导入项目根目录 `/Users/yangl/IdeaProjects/wmall`，确认AppID为上述测试号，然后点击“编译”。开发版本明确连接本机18080端口；体验、正式和未知版本不会使用开发身份或模拟支付。开发者工具如提示本地HTTP地址不合法，在本项目“详情 → 本地设置”中开启“不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书”，仅用于开发者工具联调。

该地址供本机模拟器使用。手机中的 `127.0.0.1` 指向手机本身，不能直接用于真机调试；需要真机联调时再单独配置可达地址和受控的开发接入。

## 测试账户与流程

所有页面顶部显示“本机联调 · 模拟支付不会扣款 · 独立测试数据”。首次默认“测试新客”。进入“尊享会员”，点击“切换新客”“切换会员”或“切换掌柜”即可切换；这是独立开发身份，不是实际微信授权。

| 账户 | 首次初始化状态 | 适合验证 |
| --- | --- | --- |
| 测试新客 | 非会员、无积分红包 | 原价、满68元晋级、绑定推荐人 |
| 测试会员 | 会员、200积分、20元测试红包、累计120元 | 会员价、抵扣、资产流水、推荐奖励 |
| 测试掌柜 | 仅后台权限，无会员赠送资产 | 菜品、库存、设置、订单履约、售后与日报 |

重启不会重置上述账户后续产生的状态。会员的初始邀请码为 `LOCAL-MEMBER`，可复制到新客绑定流程；推荐奖励须在订单完成后到账。店铺初始开放接单，每道测试菜品默认40份，自送小区为“联调小区”和“测试小区”。门店地址、电话、样品图片和账户资产都仅用于联调，不代表经营者真实资料。

推荐验证顺序：

1. 新客选菜、填写联系人和测试电话、选择自提或测试小区，提交订单。
2. 正金额订单支付时选择“模拟付款成功”“模拟付款失败”或“模拟取消付款”。失败/取消保留待付款订单，可在“我的订单”重试；模拟成功由后端校验订单所有权、金额及付款时限后入账。零元订单沿用正常零元确认流程，不弹出付款选择。
3. 切换测试掌柜，从会员页进入后台，查看备餐和库存。自提须先“备好”，再用顾客订单中的自提码核销；自送须先发车，再确认送达。履约仍遵守当日预约规则，不能在今天核销明天的预约单。
4. 切回顾客，核对订单状态、积分、累计消费；测试推荐奖励在完成前后是否可用。
5. 测试备餐前取消，以及完成后的掌柜售后整单退款；模拟退款自动成功，沿用正常的库存/积分/红包返还及奖励冲正。已消费的餐品不会因为售后退款重新变为可售。

经营规则仍是16:00截单、16:30批次、可预约次日。当天已过截单时间时选择次日；如需当天完成履约联调，可由测试掌柜在本机后台将截单/出炉时间调整到当天稍后，保持截单早于出炉。不会改动云端规则。

## 修改、日志与检查

前端修改后在开发者工具重新编译。后端修改后执行：

```sh
npm run local:restart
```

停止本机服务并保留测试数据：

```sh
npm run local:stop
```

后端日志 `.runtime/local-dev/server.log`；数据库日志 `.runtime/local-dev/mysql.log`。自动检查：

```sh
npm test
npm run local:verify
```

`local:verify` 在本机MySQL中新建随机隔离库，验证支付失败/取消、所有权、并发成功幂等、重启后查单、退款、履约赠分/冲正及超时释放，再删除该临时库，不清空你正在使用的 `pandou_local_dev`。

真实微信支付、云存储写入、云端制码、另一微信扫码及正式身份权限仍须正式小程序和云配置验收。本次不模拟云存储写入或生成可冒充真实小程序码的海报，相关能力未配置时继续明确报错。
