## 📌 一、核心业务特性与防刷风控设计

1. **同城自闭环履约**：
   - 专注临安锦城周边社区，仅支持「作坊掌柜电瓶车自送」与「到店自提（临天八弄36号）」，不设第三方外卖与长途快递，杜绝高昂抽佣与运费损耗。
2. **动态菜品上下架与沽清**：
   - 支持掌柜手机端/后台一键沽清（售罄遮罩）与恢复在售，随时录入新增出炉卤味，绝非写死静态配置。
3. **分层会员与双积分体系**：
   - **普通客官**：原价购买，消费享普通积分（满100分立减5元）。
   - **尊享会员（8.8折）**：全场享受 8.8 折专属价，享有普通积分与红包积分双账户。
   - **自愿注销/退出**：会员可随时注销身份恢复为普通客官（撤销8.8折与返佣权益，保留普通积分）。
4. **防刷 3% 推荐返佣算法（核心风控）**：
   - 好友每单消费产生 3% 红包积分奖励给推荐人。
   - **严格风控**：若好友使用红包积分抵扣货款，**被抵扣部分绝对不产生返佣**，仅按微信纯现金实付金额核算，杜绝多账号自循环刷单套现。
   - **防亏损上限**：单笔订单红包积分冲抵货款比例可在后台灵活配置（默认最高50%）。
5. **轻量化掌柜安全防护与厨房调度**：
   - 会员中心底部的「作坊后台运营控制台」设有掌柜专属口令防护（默认口令：`8899`），普通访客无权修改菜品与运营参数。
   - 作坊端支持查看当天待出锅备餐订单列表，支持单单核验派送与一键全单发车。
6. **全生命周期订单状态与事务保障**：
   - 包含创建、支付、发车派送、确认收货，以及出锅前自主取消与全额原路退款（自动回滚抵扣的普通积分与红包积分）。
   - 下单与资金核销全面采用 MySQL 8.0 行级排他锁（`FOR UPDATE`）与 ACID 强一致性事务，防范并发双花与返佣重入。

## 🚀 三、零成本上线部署全流程实操

### 第 1 步：导入与初始化数据库
1. 登录 [微信云托管控制台](https://cloud.weixin.qq.com/)。
2. 进入 **数据库** 模块，创建云托管 MySQL 8.0 实例。
3. 点击 **数据库工具 / 数据导入**（或使用 phpMyAdmin / Navicat 内网穿透连接）。
4. 导入项目根目录下的 `init.sql` 文件，自动生成 `t_system_config`、`t_product`、`t_user`、`t_order`、`t_order_item`、`t_commission_flow` 数据表及初始卤味与配置。

---

### 第 2 步：部署后端服务至微信云托管（前3个月完全免费）
1. 在微信云托管控制台，点击 **服务管理 -> 新建服务**，服务名称填入 `pandou-server`。
2. 资源规格选择：`0.25核 CPU / 0.5 GB 内存`。
3. 副本数配置：**最小副本数设为 `0`**（闲置深夜自动缩容为 0 实例，不产生任何计费），最大副本数设为 `2`。
4. 部署方式选择 **本地代码包上传** 或 **绑定 GitHub 仓库**：
   - 目标路径选择 `server` 目录。
   - 微信云托管将自动识别 `Dockerfile` 进行云端多阶段构建并部署。
5. 部署成功后，服务会自动关联到云托管私有网络，免配外部合法域名。

---

### 第 3 步：微信开发者工具打开与联调小程序
1. 打开 **微信开发者工具**，点击 **导入项目**。
2. 目录选择本项目的 `miniprogram` 文件夹。
3. AppID 填入已申请注册的小程序 AppID。
4. 打开 `miniprogram/app.js`：
   - 将 `cloudEnvId` 替换为您在云托管控制台创建的环境 ID（如 `prod-xxx`）。
   - 将 `serviceName` 确认与云托管服务名一致（默认 `pandou-server`）。
5. 点击微信开发者工具顶部菜单 **预览** 或 **真机调试**，即可在手机微信上体验完整点单、试算、抵扣、追踪与后台管理！

---

### 第 4 步：提交微信官方审核与发布
1. **服务类目设置**：
   - 进入微信小程序官方后台 -> **基本设置 -> 服务类目**。
   - 添加主营类目：`餐饮 -> 外卖/点餐`。
   - 上传潘小兜的《食品经营许可证》（许可证号：`JY13301850326102`，确保主体名称一致）。
2. **版本上传与审核**：
   - 在微信开发者工具中点击右上角 **上传**，填写版本号（如 `1.0.0`）。
   - 进入小程序后台 **版本管理** 提交审核。
   - 审核通常在 2～12 小时内完成。审核通过后点击 **全量发布**，街坊邻居即可直接搜索或扫码下单！
